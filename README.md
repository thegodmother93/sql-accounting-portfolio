# SQL Accounting Portfolio

Hello, I am Monicah Maina. I have a background in procurement and supply chain, and I am learning SQL by building real-life accounting projects.

This repository documents my journey from beginner to advanced.

## My Goal
To use SQL to solve real accounting problems such as ledgers, payables, receivables, financial statements, reconciliations and audit checks.

## My Vision
Bookkeeping is slow when every step is done by hand. My focus is to build one system that automates the whole accounting process, from source documents to financial statements, and brings in human expertise only where it is truly needed.

I am building this step by step, one project at a time, and documenting what I learn.

## How the System Will Work
1. **Collect** source documents such as invoices, receipts, bank and M-Pesa statements.
2. **Extract and clean** the data.
3. **Classify** each transaction using rules stored in MySQL.
4. **Post** balanced journal entries automatically.
5. **Review** anything unusual or uncertain. This step is done by a human.
6. **Reconcile** the bank statement with the ledger.
7. **Produce** the trial balance, income statement and balance sheet.

Automated: data cleaning, classification of clear items, posting, balance checks, matching and statements.
Human review: unclear transactions, adjusting entries, tax and final sign-off.
